## What I care about

- **Evidence-grounded AI:** every claim cites a source, and unsupported output gets blocked
- **Evaluation that includes refusal:** testing whether a system declines to answer when it should
- **Privacy by design:** offline-first assistants, and data handling that excludes personal data and outcome-revealing fields
- **Governance and ethics** as engineering requirements, not afterthoughts
